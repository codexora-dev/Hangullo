# Hangullo 문법 v0.0.1-beta

## 1. 파일

Hangullo 소스 파일의 확장자는 `.hg`입니다. 소스는 UTF-8로 저장합니다.

```powershell
python main.py 파일.hg
python main.py 파일.hg --실행
```

## 2. 주석과 줄바꿈

한 줄 주석은 `#` 또는 `//`로 시작합니다. 문장은 줄바꿈으로 구분합니다.

```hangullo
# 설명
// 설명
출력("Hello")
```

빈 줄은 무시됩니다.

## 3. 식별자와 리터럴

식별자는 한글, 영문, 숫자, 밑줄을 사용할 수 있지만 숫자로 시작할 수 없습니다. 예약어는 식별자로 사용할 수 없습니다.

지원하는 리터럴은 정수, 실수, 문자열, `참`, `거짓`입니다. 문자열은 큰따옴표로 감싸며 `\\n`, `\\t`, `\\"`, `\\\\` 이스케이프를 지원합니다.

## 4. 출력과 입력

```hangullo
출력("Hello")
출력(2 + 3 * 4)
입력(이름)
입력(이름, "이름을 입력하세요: ")
```

`입력`은 첫 번째 인수로 입력을 저장할 변수 이름을 받고, 두 번째 인수로 선택적인 프롬프트를 받습니다. 다음처럼 대입식에도 사용할 수 있습니다.

```hangullo
변수 이름 = 입력(이름, "이름: ")
```

## 5. 변수와 대입

```hangullo
변수 이름 = "Hangullo"
이름 = "새 값"
```

## 6. 연산자와 우선순위

지원 연산자는 `+`, `-`, `*`, `/`, `%`, `==`, `!=`, `>`, `>=`, `<`, `<=`, `그리고`, `또는`, `아니다`입니다. 대입에는 `=`를 사용합니다.

우선순위는 괄호, 단항 연산, 곱셈/나눗셈/나머지, 덧셈/뺄셈, 비교, 같음 비교, `그리고`, `또는` 순서입니다.

## 7. 조건문

블록은 콜론 뒤에 들여씁니다. 블록을 닫는 `끝` 키워드는 사용하지 않습니다.

```hangullo
만약 점수 >= 90:
    출력("A")
아니고만약 점수 >= 80:
    출력("B")
아니면:
    출력("C")
```

## 8. 반복문

`반복`은 횟수만큼 실행합니다. 현재 구현은 Python의 `range(int(횟수))`와 같은 동작을 사용하므로 0과 음수는 실행하지 않고, 실수는 정수로 변환합니다.

```hangullo
반복 3:
    출력("반복")
```

## 9. 함수와 반환

```hangullo
함수 더하기(가, 나):
    반환 가 + 나

변수 결과 = 더하기(3, 5)
출력(결과)
```

함수 호출은 표현식 안에서도 사용할 수 있습니다. `반환`은 함수 안에서만 사용할 수 있습니다.

## 10. 들여쓰기

들여쓰기 단위는 공백 4칸을 권장합니다. 같은 블록의 들여쓰기 깊이는 일치해야 합니다. IDE는 콜론 뒤 Enter에서 자동 들여쓰기를 제공합니다.

## 11. 지원하지 않는 기능

v0.0.1-beta에서는 컬렉션 반복, `계속`, `종료`, 클래스, 모듈, 예외 처리, 사용자 정의 타입, 자체 VM과 바이트코드를 지원하지 않습니다.
