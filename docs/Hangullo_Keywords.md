# Hangullo 예약어 v0.0.1-beta

| 예약어 | 의미 | 상태 |
|---|---|---|
| `출력` | 값을 화면에 출력 | 지원 |
| `변수` | 변수를 선언 | 지원 |
| `입력` | 사용자 입력을 변수에 저장 | 지원 |
| `만약` | 조건문 시작 | 지원 |
| `아니고만약` | 추가 조건 분기 | 지원 |
| `아니면` | 조건의 나머지 분기 | 지원 |
| `반복` | 횟수 기반 반복 | 지원 |
| `함수` | 함수 정의 | 지원 |
| `반환` | 함수에서 값을 반환 | 지원 |
| `참` | 참(Boolean) 값 | 지원 |
| `거짓` | 거짓(Boolean) 값 | 지원 |
| `그리고` | 논리 AND | 지원 |
| `또는` | 논리 OR | 지원 |
| `아니다` | 논리 NOT | 지원 |

## 식별자 규칙

예약어는 변수명, 함수명, 매개변수명으로 사용할 수 없습니다. 식별자는 한글 또는 영문/밑줄로 시작하고 숫자와 밑줄을 이어 쓸 수 있습니다.

## 블록 규칙

`만약`, `아니고만약`, `아니면`, `반복`, `함수` 뒤에는 콜론을 쓰고 다음 줄을 들여씁니다. 블록을 닫는 별도 키워드는 없습니다.

```hangullo
함수 인사(이름):
    출력(이름)
```

지원하지 않는 `클래스`, `계속`, `종료`, `가져오기`, `내보내기` 등은 예약어로 등록되어 있지 않으며 v0.0.1-beta 범위에 포함되지 않습니다.
